# Security and responsible use

Do not include credentials, real personal documents, packet captures, tokens or private data in issues, test fixtures or screenshots. Use synthetic examples. Report sensitive issues privately through GitHub private vulnerability reporting when enabled; otherwise contact the repository owner privately without publishing exploit data.

Dependency updates are proposed by Dependabot and must pass CI before merging. This is a portfolio project, not a claim of production security certification. See README for deployment boundaries and known limitations.
